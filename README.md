# CYDRA Experience Lab

An interactive QA portfolio built around a browser-local fictional storefront. Visitors can search and filter products, add items to a cart, reproduce a deliberately seeded price mismatch, record an observation, reveal reference evidence, and download a Markdown report.

## Transparency

- The price mismatch is synthetic and intentionally seeded for this demo.
- The report explicitly labels the scenario synthetic; it is not a real client finding or security vulnerability.
- Demo interactions do not submit purchases, collect credentials, or test external targets.
- No build step or package installation is required; the site is a self-contained `index.html`.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under build and deployment, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages deployment to complete. The expected URL is https://Wonderadroit.github.io/.
